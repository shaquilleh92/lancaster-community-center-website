# Lancaster Community Center Website

## Project Overview

The Lancaster Community Center Website is a community-focused web project designed to provide users with a centralized location for information about programs, services, resources, and community opportunities.

The project focused on creating a professional, accessible, and user-friendly digital presence while organizing information in a way that allows community members to quickly locate relevant resources.

## My Role

**Web Project Developer / Website Designer**

I was responsible for planning, designing, organizing, and publishing the website. My responsibilities included:

* Planning the website structure and navigation
* Organizing content based on user needs
* Designing and developing the website using Wix
* Creating and organizing website content
* Structuring pages and navigation
* Implementing responsive layouts for desktop and mobile users
* Reviewing website usability and functionality
* Testing navigation, links, and page content
* Making revisions based on project requirements
* Publishing the completed website
* Maintaining and updating website information

## Business & Community Need

Community organizations need a centralized digital presence where users can easily find information about available programs, services, resources, and contact information.

This project addressed that need by organizing important community information into a structured website that users can access from desktop and mobile devices.

## Project Development Process

### 1. Identify the Need

Identified the need for a centralized online resource where community members could access important organizational information.

### 2. Gather & Organize Requirements

Reviewed the information and resources that needed to be presented and organized them into logical website sections.

### 3. Design the Website

Planned page structure, navigation, content organization, and overall visual presentation.

### 4. Develop the Website

### 7. Publish

Published the completed website and made it accessible to the community.

### 8. Maintain

The website can be updated as programs, resources, contact information, and other community information change.

## Challenges & Solutions

### Challenge: Organizing Community Information

Community information needed to be presented in a way that allowed users to locate relevant resources without unnecessary navigation.

**Solution:** Organized information into logical website sections and developed navigation around the needs of the intended users.

### Challenge: Mobile Usability

The website needed to remain usable across different screen sizes.

**Solution:** Reviewed the website across desktop and mobile layouts and adjusted content presentation and page structure where necessary.

### Challenge: Maintaining Current Information

Community programs, resources, and contact information may change over time.

**Solution:** Used a content management platform that allows website information to be updated without rebuilding the entire website.
